# ドット絵メーカー

写真やイラストを、レトロゲーム風のドット絵に変換するブラウザアプリです。
画像は端末の中だけで処理され、外部には送信されません。

## 機能

- 画像を選ぶか、プレビューにドラッグ＆ドロップして読み込み（JPG・PNG・WebPなど。透過PNGも可）
- 8種類のパレットから選択
  - ファミコン風 / ゲームボーイ風 / PICO-8風 / 赤と黒 / セピア / ネオン / グリーンモニター / ゆめかわパステル
- ドットの粗さ・明るさ・コントラストをスライダーで調整
- ディザ（網点）のあり／なし
- ドットの形（四角／丸）
- 「ドット絵」と「元画像」の切り替え
- 拡大したPNG画像として保存

## 使い方

`index.html` をブラウザで開くだけで動きます。

## GitHub Pages で公開する

1. リポジトリのルートに `index.html`（と、この `README.md`）を置く
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（画面・見た目・変換処理・サンプル画像をすべて含む） |
| `README.md` | この説明 |

外部ライブラリは使っていません。フォント（DotGothic16、Zen Kaku Gothic New）だけ Google Fonts から読み込みます。

## カスタマイズ

`index.html` の中を直接編集します。

- **パレットを増やす**: `<script>` 内の `PALETTES` に1行足します。`mono: true` にすると、画像を明るさだけで見て色を割り当てます（グレー系や単色系向き）。
- **サンプル画像を変える**: `window.SAMPLE_DATA_URL = "data:image/jpeg;base64,..."` の行を、別の画像の data URL に置き換えます。この行は非常に長いので、エディタで「SAMPLE_DATA_URL」を検索すると見つかります。
- **色や文字の大きさを変える**: `<style>` の先頭にある `:root { ... }` の色の指定を変えます。

## 補足

- 「ファミコン風」「ゲームボーイ風」「PICO-8風」は、それぞれの雰囲気に近づけた配色です。各製品や制作元とは関係ありません。
- 画像は最大1000px程度に縮小してから処理します。
